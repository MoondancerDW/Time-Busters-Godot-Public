# Time Busters Godot R12

Порт Bugs Bunny & Taz: Time Busters для Windows x64 на Godot. [Выпуск R12](https://github.com/MoondancerDW/Time-Busters-Godot-Public/releases/tag/r12-final) содержит полную игру с игровыми данными, архив исходников и контрольные суммы.

Распакуйте Time-Busters-Godot-r12-final-runtime.zip и запустите Play-Time-Busters.cmd. Для редактирования, сборки и проверки изменений скачайте также Time-Busters-Godot-r12-final-source.zip. В нём находятся исходники, заголовки и статические библиотеки для пересборки модуля.
