# Сборка и моддинг Time Busters R12

Проверьте SHA-256 архивов по файлам .sha256 из релиза. Распакуйте runtime и source в отдельные папки. Для игры запустите Play-Time-Busters.cmd из папки runtime. Сохранения создаются в профиле Windows.

## Проект Godot

Скопируйте папку project из runtime в рабочую папку. Откройте её project.godot в Godot 4.7.2-stable. В runtime уже есть данные оригинала, звуки и нативный модуль. Каталог godot-accepted содержит принятые файлы проекта Godot. Скопируйте изменённые файлы из него в рабочий проект для проверки.

## Нативный модуль

Для пересборки нужен Python 3.12 или новее и LLVM-MinGW UCRT x86_64 версии 20261020. Возьмите комплект LLVM-MinGW из [релизов инструментария](https://github.com/mstorsjo/llvm-mingw/releases). Архив исходников содержит необходимые заголовки и пять статических библиотек. Source-manifest.json фиксирует комплект и идентификатор исходной сборки R12.

Из распакованной папки source в PowerShell выполните команду:

    py -3 .\extras\rebuild_native.py --toolchain C:\Tools\llvm-mingw --output ..\r12-native --build

Укажите путь к распакованному LLVM-MinGW. Выберите новую папку результата. Без --build команда проверяет входы и печатает план. Ключ --unit tb_steer позволяет быстро пересобрать отдельный модуль. При изменении заголовков игровых механик пересоберите все модули. Замените bin\tb_reference.dll в копии проекта новой DLL и запустите игру для проверки.

Скрипт компилирует игровые модули и мост, затем линкует DLL с библиотеками из комплекта. Исходники bbtime и заголовки зависимостей включены. Исходная версия [godot-cpp](https://github.com/godotengine/godot-cpp/tree/e103d348c4b2d8df7b819126d855e19381cb9a87) указана для отдельной сборки SDK.

Правила и примеры замены моделей, текстур и звуков находятся в [ModKit](extras/modkit-portable/README.md).
