# Моды Time Busters R12

Для установки нужны распакованная сборка R12 для Windows и Python 3.11 или
новее. Распакуйте мод отдельно. Путь к копии игры должен быть новым.

```powershell
$runtime = 'C:\Games\Time Busters R12'
$kit = 'C:\Games\Time Busters R12 source\extras\modkit-portable'
$project = Join-Path $runtime 'project'
$copy = 'C:\Games\Time Busters R12 cosmetics'
$example = Join-Path $kit 'example-arabia'
$tool = Join-Path $kit 'modkit.py'
py -3 -B -X utf8 $tool validate $example
py -3 -B -X utf8 $tool check --project $project
py -3 -B -X utf8 $tool install --project $project --destination $copy
& (Join-Path $runtime 'Godot_v4.7.2-stable_win64.exe') --path $copy -- "--cosmetic-mod=$example"
```

`check` сверяет отпечатки сборки и места подключения. `install` создаёт отдельный
проект, сверяет нативную DLL и назначает копии собственное имя каталога
`user://`. Продолжайте штатную игру через её `Play-Time-Busters.cmd`.
В установленной копии мод включается только указанным каталогом, через
`--cosmetic-mod=<путь>` или `TIMEBUSTERS_COSMETIC_MOD`.
Отдельный запуск копии с `--no-cosmetic-mod` отключает подмены, включая
указанный через переменную мод. Для диагностики запускайте консольный
`Godot_v4.7.2-stable_win64_console.exe` и добавляйте `--cosmetic-trace`
после разделителя `--`.

На Windows проверена установка в копию упакованного кандидата R12.
В обычном маршруте по Аравии куб заменял ящик в позе покоя. При отскоке
появлялась штатная модель, после разрушения ящик исчезал. Четыре звуковых
события использовали PCM из примера. В обоих запусках совпали награда и
все 768 байтов игрового состояния при сохранении и продолжении.

Эта проверка звука измеряет выходной поток PCM. Громкость на конкретном
устройстве зависит от настроек Windows.

## Модели

Скопируйте `example-arabia` в свою папку, замените модель и отредактируйте
`mod.json`. Инструмент `example <новая-папка>` создаёт тот же пример
с моделью. Чтобы добавить звук, укажите `--sound-blob 5`.
Используйте автономный GLB 2.0 с мешами и встроенными текстурами.

- `TB_COSMETIC_MODEL` показывает SHA-256 ресурса уровня, `source_chunk`,
  `source_id`, признак `eligible` и текущие размеры. Версии RU и EN могут
  иметь разные SHA-256. Каждая тройка выбирает один размещённый в уровне
  объект.
- Схема 2 требует `reference_extent_m` с шириной, высотой и глубиной
  штатного меша при нейтральной позе в метрах. Разместите начало координат
  GLB в исходной точке опоры и используйте штатный размер как ориентир.
  Поворот и положение следуют жёсткому объекту. Масштаб вычисляется по
  размерам отрисованных нативных вершин относительно заданного эталона.
  Дополнительный множитель `scale` по умолчанию равен `1`.
- Поддерживаются размещённые жёсткие объекты с тремя ненулевыми размерами
  и без активных частей позы. Включён точечный пример бирюзового куба
  размером 0,21 м и с опорой на нижнюю грань. Он выбирает ARCA01 RU,
  chunk 84429, ID 253, только пока геометрия ящика совпадает с проверенной
  позой покоя.
- Игроки, создаваемые динамически объекты, райдеры, крепления, скелеты,
  многокомпонентные и анимированные позы используют штатную модель.
  Для зеркальных преобразований и замены целых ролей требуется
  дополнительный контракт данных нативной части. При пропаже модели,
  неподдержанной позе или ошибке импорта игра показывает штатную
  геометрию. Коллизии и разрушение выполняются штатным кодом.

## Звуки

Используйте PCM WAV 16 бит, моно или стерео, 8–192 кГц. Ключ однократного
эффекта состоит из SHA-256 ресурса и `blob` с нумерацией 1–127. Ищите
`TB_COSMETIC_SFX` в журнале. В примере выбран только blob 5 ресурса
ARCA01 RU, а `click.wav` содержит синтезированный тон.
`TB_COSMETIC_SFX_REPLACED` подтверждает подмену выходного PCM и показывает
его хеш. Выходная длительность, частота, громкость и регулировки
остаются штатными. Музыка, XA-речь и циклические звуки используют
штатный звуковой путь.

Один манифест допускает до 64 записей каждого типа. Используйте
доверенные обычные файлы, без ссылок или junction. `validate` проверяет
пути и контейнеры, а допустимое дерево сцены дополнительно проверяется
при импорте Godot.

## Механики

Откройте отдельную копию **полного актуального** source kit. В ней
нужны `source-manifest.json`, `native/reference/engine/game`,
`native/bridge`, `native/libraries`, `native/sdk`, `port-commit.zip`
и `extras/rebuild_native.py`. Используйте инструкцию пересборки из
`extras`. Для R12 C1 нужен `rebuild_native_v2.py` с SHA-256
`542168a1017f015736fe94200eca8874c77225c9386d007b86cdbeb75d978f65`,
упакованный как `extras/rebuild_native.py`. В `port-commit.zip` он
загружает `tests/native_audio/owned_process_v5.py` с SHA-256
`1570ec96312c22633f3c3ad3a5da79199d55774d57653ec087fbd4645e1ae090`.

Изменяйте нужный модуль. Движение и управление находятся в
`tb_steer.cpp` и `tb_mover.cpp`, взаимодействия в `tb_entities.cpp`,
мир в `tb_world.cpp`, сохранение в `tb_save.cpp`. Храните свои правки
рядом с копией исходников. Нужны Windows x64, Python и LLVM-MinGW
20261020 UCRT x86_64 с Clang 23.1.4.

```powershell
$source = (Resolve-Path '.\Time-Busters-R12-source-working').Path
$toolchain = (Resolve-Path '.\llvm-mingw-20261020-ucrt-x86_64').Path
$output = Join-Path (Get-Location) 'Time-Busters-R12-native-mod'
$builder = Join-Path $source 'extras\rebuild_native.py'
py -3 -B -X utf8 $builder --source-root $source --toolchain $toolchain --output $output
py -3 -B -X utf8 $builder --source-root $source --toolchain $toolchain --output $output --build
```

По умолчанию пересобираются все 22 игровых модуля и bridge. Если меняется
только тело файла `tb_steer.cpp`, укажите `--unit tb_steer` в обеих
командах. При изменении заголовка запустите полную сборку. Помощник
переиспользует проверенные библиотеки core и SDK. DLL из нового каталога
проверяйте в отдельной копии runtime после установки косметики, если она
нужна. Проверьте изменённое действие, соседнее взаимодействие, запись из
паузы и холодную загрузку копии прежнего сохранения.
